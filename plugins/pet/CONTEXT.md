# Pet

DSH Web 界面里的状态驱动悬浮宠物：一个动画角色陪伴会话，通过动画实时反映会话状态。

## Language

**宠物 (Pet)**:
悬浮在 Web 界面上的动画角色，通过播放动画反映当前会话的状态。
_Avoid_: 桌宠, 伙伴, mascot

**宠物包 (Pet Package)**:
定义一只宠物外观与动画的资源包——一份元数据文件加一张帧图集，与 Codex 桌面宠物包格式兼容。
_Avoid_: 皮肤, 主题

**状态 (State)**:
宠物动画所绑定的会话状态，如空闲、工作、等待、失败。
_Avoid_: 模式, 阶段

**唤醒 (Wake)**:
令宠物出现并开始跟随会话状态；反之称为隐藏。
_Avoid_: 启动, 打开

**宠物库 (Pet Library)**:
DSH 存放宠物包的仓库；宠物包可通过导入从 Codex 宠物目录获得。
_Avoid_: 宠物目录, 商店

**导入 (Import)**:
把宠物包从 Codex 宠物目录复制进宠物库。
_Avoid_: 安装, 装载

**点击技能 (Click Skill)**:
点击宠物本体触发的宠物包内置技能动画，按宠物包定义的顺序循环播放。
_Avoid_: 招式, 彩蛋
