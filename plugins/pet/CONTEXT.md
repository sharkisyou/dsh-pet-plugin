# Pet

DSH Web 界面里的状态驱动悬浮宠物：一个动画角色陪伴会话，通过动画实时反映会话状态。

## Language

**宠物 (Pet)**:
悬浮在 Web 界面上的动画角色，通过播放动画反映当前会话的状态。
_Avoid_: 桌宠, 伙伴, mascot

**宠物包 (Pet Package)**:
定义一只宠物外观与动画的资源包——一份元数据文件加一张帧图集，与 Codex 桌面宠物包格式兼容。
_Avoid_: 皮肤, 主题

**状态 (State)**:
宠物动画所绑定的会话状态，如空闲、工作、等待、失败。
_Avoid_: 模式, 阶段

**会话 (Session)**:
一次独立对话/任务；在多会话场景中，宠物跟踪的顶层会话，子代理活动归入其父会话。
_Avoid_: 聊天, 任务, 对话

**多会话 (Multi-session)**:
宠物跨多个会话跟踪活动，并同一时刻只展示优先级最高的那个会话。
_Avoid_: 多标签, 多窗口

**活动托盘 (Activity Tray)**:
列出当前有活动的会话的浮层；用户可点击某项切换到对应会话。
_Avoid_: 会话列表, 通知中心

**活动会话 (Active Session)**:
处于非空闲状态的会话，包括需要输入、受阻、就绪、运行中。
_Avoid_: 打开的会话, 最近会话

**需要输入 (Needs input)**:
会话正在等待用户批准、回答或其他决定。
_Avoid_: 等待中, 待处理

**受阻 (Blocked)**:
会话失败或遇到系统错误。
_Avoid_: 错误, 故障

**就绪 (Ready)**:
会话已完成且有未读的新活动；工作区中以绿点提示。
_Avoid_: 完成, 待查看

**运行中 (Running)**:
会话正在积极工作。
_Avoid_: 工作中, 处理中

**唤醒 (Wake)**:
令宠物出现并开始跟随会话状态；反之称为隐藏。
_Avoid_: 启动, 打开

**宠物库 (Pet Library)**:
DSH 存放宠物包的仓库；宠物包可通过导入从 Codex 宠物目录获得。
_Avoid_: 宠物目录, 商店

**导入 (Import)**:
把宠物包从 Codex 宠物目录复制进宠物库。
_Avoid_: 安装, 装载

**点击技能 (Click Skill)**:
点击宠物本体触发的宠物包内置技能动画，按宠物包定义的顺序循环播放。
_Avoid_: 招式, 彩蛋
