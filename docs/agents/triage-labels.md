# Triage 标签

各技能使用五个标准分流角色来表达意图。本文件将这些角色映射到本仓库 issue 追踪器中实际使用的标签字符串。

| 技能中的角色 | 本仓库标签 | 含义 |
| ------------ | ---------- | ---- |
| `needs-triage` | `needs-triage` | 维护者需要评估该 issue |
| `needs-info`   | `needs-info`   | 等待报告者提供更多信息 |
| `ready-for-agent` | `ready-for-agent` | 规格已完备，可供 AFK 代理处理 |
| `ready-for-human` | `ready-for-human` | 需要人工实现 |
| `wontfix`      | `wontfix`      | 不会处理 |

当技能提到某个角色（例如"应用 AFK-ready 分流标签"）时，使用本表中对应的标签字符串。

如需适配你实际使用的词汇，直接编辑右侧一列即可。
